# SMS Bridge — גרסת 0.3, ממשק פשוט

## חוויית המשתמש
- אין צורך להקליד קישור לשרת: הוא מוכנס בזמן בניית ה-APK דרך משתנה GitHub Actions בשם `BRIDGE_SERVER_URL`.
- באפליקציה מזינים רק מספר WhatsApp פעם אחת. **אין קוד חיבור חד-פעמי** כפי שהתבקש.
- עם פתיחת האפליקציה מוצגת בקשת הרשאת SMS בהודעה ואז חלונית הרשאה של Android.
- לאחר החיבור וההרשאה, השליחה מסומנת פעילה אוטומטית.
- ברירת המחדל של SIM להודעות נבחרת לפי הגדרות Android. אם אין ברירת מחדל יש להגדיר אותה במכשיר.
- ניתוק מכשיר נמצא בהגדרות (גלגל שיניים), ולא על המסך הראשי.
- בשרת הניסוי `/device/register` מחליף את החיבור בקוד.

## לפני בנייה
1. השאר את ה-Worker הקיים של WhatsApp ללא שינוי.
2. פרוס **בנפרד** את `staging-worker/index.js` עם D1 חדש לפי `staging-worker/schema.sql`.
3. הגדר את `ADMIN_TOKEN` ו-`GOOGLE_SERVICE_ACCOUNT_JSON` ב-Worker הנפרד לפי מדריך Firebase שלך.
4. במאגר GitHub של האפליקציה, עבור אל Settings → Secrets and variables → Actions → Variables, הוסף `BRIDGE_SERVER_URL` עם כתובת ה-HTTPS האמיתית של שרת הניסוי. **לא לשים API token בקישור**.
5. הגדר Firebase Android עם application ID `il.smsbridge.app` והעלה ל-GitHub Actions את `FIREBASE_JSON_BASE64` בתור secret. לא לפרסם קובץ JSON או מפתח חשבון שירות במאגר הציבורי.
6. הרץ Build Android APK ב-Actions. אין צורך ב-Android Studio על Windows.

## מגבלות חשובות
- זוהי **חבילת קוד לפיתוח**, לא APK שעבר קומפילציה ובדיקת מכשיר.
- גרסה זו משתמשת בשיוך לפי מספר טלפון שהמשתמש מזין בלי אימות. זו פשרה על אבטחה שנבחרה כדי לבטל את קוד החיבור; אין לפרוס שרת רישום כזה לציבור הרחב ללא הגבלת גישה חיצונית.
- אפליקציה זו עדיין אינה מחוברת ל-Worker WhatsApp הראשי. שילוב SMS4FREE כגיבוי עדיין דורש פיתוח ובדיקה.
- Android עשוי להגביל עבודה ברקע; פעולת ההודעה תלויה ב-FCM ובתנאי המכשיר.
- תוצאת `MODEM_ACCEPTED` אינה הוכחת מסירה לנמען.
- אין לשתף עם ציבור את קוד ההרשאות או מפתחות השרת.
- הפיכת שליחה לאוטומטית היא שינוי מפורש שביקשת באפליקציה בלבד; קוד ה-Worker הפעיל לא השתנה.
